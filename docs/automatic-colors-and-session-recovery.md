# 自动配色与官方 App 联动修复

## 已复现的原因

- 旧安装的 `follow_cover_colors=false` 持续覆盖自动模式，升级没有迁移入口。旧固定颜色和材质组合因此可一直保持不变。
- 自动滤镜在经典黑胶的暗像素上只加入少量封面颜色。原生红/蓝封面实测，盘面平均红/蓝通道差仅约16.5 / 14.5；素材暗部压住了配色。
- `AlbumPalette.from` 遇到硬件 Bitmap 原先直接返回同一灰色；系统媒体会话封面可以属于这种类型。
- 官方联动读取会话前要求进程静态 `listenerConnected=true`。系统授权已存在但回调延迟、进程重建或旧监听实例销毁时，仍会卡在“等待系统连接”，甚至根本不向系统查询实际会话。
- 通知使用权刚授予时，权限观察器只刷新页面，没有主动申请重新绑定监听服务。

## 修复后的行为

### 配色

升级首次启用自动模式，保留已保存的手动颜色、专辑专属材质和自选封面；之后主动切换手动模式会正常持久化，不会每次启动强制打开自动。外观编辑中新增明确的“背景和唱片随封面配色”开关与当前模式说明；选固定色仍切换为手动。

自动滤镜以材质亮度保留沟纹、泼墨与明暗，增加可辨识的封面色基础量，降低素材原本紫/蓝颜色对新色的污染。手动模式清除滤镜，恢复原材质；封面标签和唱臂不染色。9种实际材质均通过红/蓝对照；经典黑胶最低差异提升至约37.9 / 34.1，其他材质更高。

硬件封面先做临时软件读回，按原有最多4096个像素的取样规则提取颜色，随后释放临时图；不修改、回收或长期持有系统提供的封面。分配/读取失败退回中性色。普通软件封面仍不复制整图。

MainActivity 同步更新每次封面配色；缺失外部封面时使用中性回退。DesignSystem 对无彩封面保持中性，不再强制给灰色添加红色饱和度。以上两个集成文件由主任务负责。

### 系统联动

通知使用权仍是必要条件。授权后，实际 `MediaSessionManager.getActiveSessions(监听组件)` 查询成功即可证明会话访问可用，不再把进程回调标记当作唯一条件。查不到正在播放的官方会话时显示“请先播放”，不会假称连接成功。

刚授权、服务断连或系统暂未完成授权传播时请求重新绑定，并在前台按退避间隔恢复查询；暂停页面、关闭桥接或撤销授权会取消待执行重试和观察。新监听实例拥有连接状态，旧实例的销毁不会抹掉新连接。状态展示中的成功探测不会提前结束重试；只有完整读取会话并装好会话变化监听后才结束恢复，避免授权在同一帧内刚生效时错停在“请先播放”。

QQ、汽水、Apple联动仍只接受各自精确官方包名；汽水为 `com.luna.music`。不按应用名称或包名前缀宽泛匹配，也不接入其他音乐 App 的会话。没有设备证据时不假设 ColorOS 双开包名或绕过跨用户权限。

## 验证与边界

- 红测：旧固定模式、黑胶配色不明显、授权后无回调仍卡住、授权授予不重绑、旧监听销毁覆盖新连接。
- 绿测：旧配置迁移仅一次、手动开关可返回、9种真实材质颜色/纹理/封面标签像素、标准取色、主播放页换封面、组件配色、颜色对话框取消和短横屏、系统授权传播重试/同帧失败后成功仍完成绑定/暂停取消/撤权取消、包名白名单、旧监听实例隔离。
- 原生红/蓝截图：`work/automatic-color-check/automatic-{red,blue}-material-{0,5,8}.png`。
- 日志：`work/automatic-color-red.log`、`work/color-and-reconnect-red.log`、`work/color-and-reconnect-green.log`；同帧恢复竞态红/绿回归为 `work/reconnect-race-red.log` / `work/reconnect-race-green.log`。

上述为本地 Android API34 / Robolectric 验证。软件封面与材质采用原生图形；硬件 Bitmap 的配置分支采用 Robolectric legacy bitmap 模型验证，因为本环境的原生图形后端会把硬件复制降为 ARGB_8888。未声称在真实 OPPO/ColorOS、汽水账号或实体硬件缓冲区上验收。

## 官方依据（2026-11-09查阅）

- [Android MediaSessionManager](https://developer.android.com/reference/android/media/session/MediaSessionManager)：启用的通知监听组件可用于查询活动媒体会话。
- [Android Bitmap官方实现](https://android.googlesource.com/platform/frameworks/base/+/master/graphics/java/android/graphics/Bitmap.java)：硬件图像复制/读回路径及调用方图像所有权。
