# 公开源码与发行包

本仓库从 0.7.7 起使用独立、干净的 Git 历史。0.7.7 初始快照对应的内部开发提交为 `63091ccd781dac28562d0434a93a0902a3dcca0f`，该提交号用于追溯，不是本仓库可检出的分支。

公开内容包括应用Java/XML/设计与演示资源、构建和依赖解析脚本、全部76个测试类、使用及技术说明、第三方许可。额外整理了GitHub主页、问题模板和公开文件检查。

以下内容保留在开发者本机，不上传：原安装包签名私钥、账号会话与配置、Maven/SDK二进制依赖、本地缓存和调试记录、旧私有源码ZIP。Apple SDK需从官方入口自行下载。停用汽水直连的厂商网页安全脚本也未纳入公开快照，其原输入摘要记录在 [排除资源清单](excluded-legacy-assets.json)；当前官方App联动不依赖它们。

0.7.7 发行包保留最初验收的原始字节。0.7.8 发行包使用本公开源码构建，以原发行签名签署对齐后的 APK，支持同签名升级；已停用的汽水直连网页资源不在 0.7.8 发行包中。公开源码自行构建使用新生成的开发签名，不能直接覆盖该发行包；请使用独立测试设备或先妥善处理旧安装的数据。重新编译本身不改变第三方平台的权限要求。

不要直接把旧开发目录的Git历史或旧源码ZIP推送到本仓库；它们曾包含签名文件。后续更新在本公开目录中合并应用源码与文档，运行 `python3 tools/check_public_repo.py` 检查待发布文件。
