# 统一歌曲与音乐人搜索

主搜索页直接查询可用音乐目录，不先让用户选择来源；歌曲结果显示封面、歌名、歌手、专辑和已知的播放权益要求。音乐人结果直接来自平台歌手搜索接口，展示头像、名称与简介，点击进入其三章主页。列表不显示平台标签；账户管理保留平台名称，便于正式授权和退出。

## 两类结果独立加载

- QQ 与网易云使用各自真实的歌曲及歌手搜索能力；Apple Music 仅在本机已有用户授权及开发者配置时参加。未配置服务或未实现歌手搜索的来源明确跳过，不调用假接口。
- 歌曲与音乐人分别拥有有界执行器、请求代次、会话代次、分页、超时和失败重试。三个歌曲请求同时阻塞时，音乐人仍可独立返回；一种结果失败不会擦除另一种结果。
- 输入停止 350 毫秒后搜索。切换关键词立即清除旧结果并取消旧请求；关键词代次和账户会话代次双重校验，页面关闭后拒绝迟到响应。授权或退出后宿主调用 `refresh()`。
- 歌曲“加载更多”和音乐人“更多音乐人”独立分页；“重试音乐人”只重试失败的歌手请求。没有匹配音乐人、音乐人请求失败与没有配置的来源分别处理。
- 页面恢复只保存关键词、两类已加载数量、歌曲列表位置与音乐人横向位置，不把凭据、完整目录或签名播放地址写入页面状态。改关键词会回到音乐人列表开头。

## 音乐人身份与头像

`MusicProvider.searchArtists(query, offset, limit)` 返回真实 `Artist`，身份始终为 `providerId + artist.id`。不同 ID 的同名艺人保留独立入口，跨平台同名也不凭名字合并。主页导航传递 `ArtistResult` 的提供方和真实艺人对象，不构造伪造歌曲作种子；即使歌曲结果为空或失败，音乐人仍可进入主页。折叠/重建时保存与恢复相同的目录身份。

已经移除旧版从歌曲 credits 推导歌手的逻辑。主页简介、歌曲与专辑仍由对应目录接口补全，受平台实际能力和账号条件影响。

卡片只使用歌手响应的头像地址；没有头像或图片加载失败时显示名字首字，不借用专辑图假装肖像。头像按可见范围及少量相邻卡片加载，避免几十张离屏头像占用歌曲封面加载队列。旧关键词留下的卡片不能导航。

## 歌曲版本、封面与权益

仅在歌名、歌手、专辑及秒级时长一致时合并；Live、Remix、不同专辑仍为不同结果，未知专辑或时长不猜测归并。每行保存所有真实候选，播放服务按实际授权和可播放性尝试，不伪造资源或解锁会员歌曲。

VIP、单独购买及混合候选的已知要求会在播放前显示；未知要求不标为免费，也不等同于当前用户是否有会员。标签不阻止有权益用户尝试播放。多候选均未成功时，提示区分实际尝试数量和最后一次失败原因，不把单一原因断言为所有版本的结论。

首选候选没有封面地址时，允许从已保守合并的同版本候选补取首个真实地址；不改变播放顺序。全部没有地址时清空图片，复用行不保留上一首封面。

## 视觉与验证边界

搜索页沿用设置页的实时柔和深色、纯色分组卡片、无衬线字体与浅色文字，系统栏同步变化。换色不重建输入框或列表。已撤下的网页来源及资料补全不再存在，用户的本地文件和既有资料不被删除。

`RealArtistSearchTest` 覆盖真实歌手响应、禁止歌曲推导、同名身份、独立执行器、分页重试、账号变更、迟到请求、超时及跳过未配置服务。`SearchArtistEntryTest` 使用原生页面验证头像/首字回退、真实点击目标、歌手结果不受歌曲失败影响、分页恢复和少量可见头像加载，并通过 MainActivity 的真实导航回调和重建检查无伪造歌曲。

原生渲染图使用明确测试目录；平台匿名联网、头像解码和最终 APK 操作有各自的验证记录。这些证据不等于私人账号整曲、会员权益或实体手机验收。
