# 使用指南

使用 iPhone 或 Mac 请见 [Apple 平台安装与功能](APPLE.md)。以下说明适用于 Android。

[返回项目主页](../README.md) · [常见问题](FAQ.md) · [反馈问题](https://github.com/liudbhx7-bot/record-room-android/issues/new/choose)

适用于 **Record Room / 唱片机 0.8.2 预览版**。在线服务的可播放范围由对应平台与账号决定；当前验证范围见[验证记录](VERIFICATION.md)。

## 安装与更新

1. 打开 [v0.8.2 Release](https://github.com/liudbhx7-bot/record-room-android/releases/tag/v0.8.2)。
2. 下载 `Record-Room-0.8.2-Android.apk`。不要把 `Source code` 源码压缩包当作安装包。
3. 在 Android 上打开 APK，按系统提示允许当前下载来源安装应用，再完成安装。
4. 系统应用信息中的版本应为 `0.8.2`，版本代码 `23`，包名 `com.recordroom.vinyl`。

最低系统为 Android 8.0（API 26），面向 ARM / ARM64 设备。最低系统要求不代表所有机型都已实测。

相同签名的旧版可以覆盖安装。若系统提示签名冲突，先确认旧包是否为自行构建或来自其他发布者；更换安装来源前保存需要保留的数据。卸载应用会清除其本机资料库记录、外观设置和登录状态，不能把卸载当成无损更新方法。

当前更新通过 GitHub Release 手动下载。设置页底部也可以查看当前安装版本。

## 本地音质和整轨唱片

- 在曲名旁点 **⋯ → 音质**，可分别查看音源格式、送入 Android 的音频流和当前输出设备。系统没有提供的硬件端规格显示为「系统未报告」。Apple MusicKit 与官方 App 联动显示各自可提供的信息。
- Android 14 及以上可开启「USB 优先使用当前采样率」。设备连在当前音乐输出路径且提供匹配配置时，播放器请求该配置。更换歌曲后可在音质面板核对报告。硬件输出是否逐比特一致需要外部设备验证。
- 导入整轨专辑时，在同一次系统文件选择中选中 `.cue` 文件和它引用的全部音频。资料库中可逐首进入、切换与拖动；原始整轨只占用一份存储。支持普通的单文件及多文件 CUE。
- 本地顺序播放会提前排入下一首，让同一播放器衔接相邻曲目。切换输出设备或音频规格时由系统重建所需的音频输出。

## 先用一首本地音乐试用

1. 进入 **设置 → 音乐与连接 → 导入本地音乐**。
2. 在系统文件选择器中选中设备上的音频，可以选择多个文件。
3. 导入后从资料库打开歌曲或专辑，点击播放。

应用读取文件中已有的歌曲、歌手、专辑及封面资料。没有这些标签的文件可能显示为“未知歌曲”“未知歌手”或“未分类专辑”；导入一首歌不会自动获得同专辑的其他音频。当前版本没有网上自动补全本地资料的功能。

移动或删除原音频、撤销文件访问权限后，对应记录可能无法播放。重新导入可重新取得可用的文件引用。

## 播放页与唱针

安装 0.8.2 后，进入播放页即可使用「浮光 01」。选一首带封面的歌曲，机身后方的封套与盘心会显示这张封面，左下盘缘随封面色调发光。

| 操作 | 行为 |
| --- | --- |
| PLAY / PAUSE | 播放或暂停当前曲目 |
| 拖动歌手名下方的进度条 | 左侧显示已播放时间，右侧显示总时长。来源支持定位时松手即可跳转，读屏也能调整进度 |
| 上一首 / 下一首 | 在当前播放队列中切歌 |
| 唱臂落到唱片上 | 在可播放状态下开始播放 |
| 沿唱片向内拖动唱针 | 调整播放进度；联动模式需要官方 App 提供定位能力 |
| 把唱臂移回右侧 | 暂停 |
| 点击唱机背景 | 显示或收起工具 |
| 点击当前歌曲或专辑入口 | 查看当前专辑及曲目 |
| 点击音乐人入口 | 进入音乐人主页；官方 App 联动时相关内容仍可能交给官方 App |

**设置 → 播放时自动收起工具** 控制悬浮入口的显隐。三个实体键和进度条常驻，点背景即可重新打开工具。

## 搜索歌曲与音乐人

点曲名旁的 **⋯ → 搜索**。首页可翻最近播放过的专辑封面，点搜索记录可重新查询，也可输入歌名、专辑名或音乐人姓名。搜索在一个页面汇总已可用的来源，不需要先选择平台。

- **音乐人卡片**：展示平台提供的真实名字和头像，点击进入对应主页。音乐人与歌曲分别加载和分页，可以单独点“更多音乐人”或“加载更多”。
- **歌曲结果**：展示歌曲名、音乐人、专辑及真实封面，点按后尝试播放。
- **需 VIP / 需单独购买**：表示目录中的播放要求，不代表当前账号已经拥有、或一定缺少相应权益。
- **部分加载失败**：成功返回的结果会继续保留；可以重试失败部分。

不同曲库中的同名歌手拥有各自的身份。应用不会仅凭相同名字把他们合成一个主页，因此可能看到多个同名卡片。音乐人页也会隔离明确属于其他身份的缓存歌曲。

搜索到歌曲后仍可能遇到账号、地区、版权、资源地址或网络限制。QQ VIP 全曲播放目前仍需真实账号进一步验证。出现错误时按[常见问题](FAQ.md)保存具体提示，不要仅凭“无法播放”推断为没有会员。

## 音乐人主页与专辑

音乐人页保留三个章节，可以使用顶部章节控制切换：

| 章节 | 内容 |
| --- | --- |
| 01 | 音乐人简介与推荐歌曲 |
| 02 | 热门歌曲 |
| 03 | 全部专辑的竖立封套架 |

第三章可以左右滑动选片，多张专辑支持首尾循环。选片触感反馈受设备和系统触感设置影响。专辑数量来自实际目录，不用重复封套增加数量。

点击封套或“打开专辑”后，封套转向正面，唱片从右侧滑出，同时提供两个入口：

- **查看曲目**：加载并打开该专辑的曲目列表。
- **播放专辑**：明确请求播放该专辑。

只打开封套不会自动播放。入口在动画过程中即可使用；继续选择另一张专辑可以中断当前展开。封面下载有独立加载过程，网络较慢时可能先看到底色。

在线专辑通过对应平台目录读取完整曲目，实际可播放范围继续受账号权益影响。本地专辑只包含已经导入的音频。目录读取失败会显示失败状态，不能把已有收藏的几首歌当作完整在线专辑。

## 音乐账户与官方 App 联动

进入 **设置 → 音乐与连接 → 音乐账户与联动**。这里有两种听歌方式，按需要选择。

### 在唱片机内浏览在线曲库

| 平台 | 操作与前提 |
| --- | --- |
| 网易云音乐 | 点击“网易云音乐”，按页面登录并浏览账号内容。 |
| QQ 音乐 | 点击“QQ 音乐 · 账号与曲库”，在官方登录页面验证自己的账号；私人歌单和会员播放仍待真实账号验收。 |
| Apple Music | 点击“Apple Music · 账号与曲库”，先配置开发者令牌，再走官方 MusicKit 授权。当前没有内置令牌服务或现成账号。 |

Apple Music 适合具备开发者配置的使用者。可导入已经签发的开发者 JWT，或配置自己的 HTTPS 令牌服务；**不应导入 `.p8` 私钥**。用户授权与订阅检查由官方 SDK 处理。详见 [Apple Music 接入](apple-music-integration.md)与[构建说明](BUILDING.md)。

退出唱片机中的平台账号只清理本应用保存的相应状态，不等同于退出手机上官方 App 的账号。Apple 的清理入口还区分用户会话和开发者配置，请阅读页面说明再选择。

### 联动已安装的官方 App

支持登记的官方 Android App 为 网易云音乐、QQ 音乐、汽水音乐和 Apple Music。**汽水当前只使用这种方式。**

1. 在手机安装并登录对应官方 App。
2. 在 **音乐来源 → 官方 App 联动** 点击 **开启播放联动**，按 Android 系统页面开启“唱片机播放联动”的通知使用权。
3. 找到所需平台，点击 **联动播放**。
4. 点击 **打开官方 App**，在官方 App 内开始播放一首歌。
5. 返回唱片机，等待曲目、封面和可用控制同步。

通知使用权用于访问 Android 的活动媒体会话。当前实现连接所选音乐 App 的播放状态，不读取或保存通知正文。开启权限只代表系统允许连接；官方 App 还必须提供正在使用的媒体会话。

联动时，播放队列、会员权益、曲库和音频输出由官方 App 管理。切歌、暂停、拖针定位等功能仅在对方声明支持时可用；音量使用手机音量键，睡眠定时在官方 App 中设置。返回本地播放可在 **音乐来源 → 手机音乐** 中点击 **使用唱片机资料库**。

## 网易云歌词与落针声

- 打开曲名旁的 **⋯ → 歌词**。唱片机内的网易云歌曲按曲目编号读取歌词。联动网易云官方 App 时，优先使用其提供的歌曲编号，缺少编号时用歌名和歌手检索，并用可用的专辑、时长核对版本。
- 有时间戳的歌词会随进度逐行加粗，暂停或拖动后也会对应到当前位置。可为当前曲目选择自己的 LRC 或 TXT 文件。网络读取失败可以重试，纯音乐会显示提示。
- 在 **设置 → 聆听体验 → 落针音效** 开启落针时的短促接触声。声音走系统媒体输出。本机播放还受应用内音量影响，联动播放跟随手机媒体音量。

## 专辑架、喜欢与播放队列

- 专辑架可在网格与立体排列之间切换，同专辑曲目归在一张专辑中。
- 长按歌曲可使用页面提供的喜欢、加入队列或歌单操作。唱片机内的本机收藏不等同于已写回平台收藏。
- 播放队列可查看当前顺序，长按拖动排序，使用菜单移除条目。
- 队列或设置中的播放模式支持 **顺序播放、列表循环、单曲循环、随机播放**。
- 官方 App 联动时，队列与模式交由官方 App 管理。

## 配色、材质与底灯

在 **设置 → 唱机外观** 中调整：

| 设置 | 用途 |
| --- | --- |
| 随封面自动配色 | 开启后，当前封面的色调用于盘面、背景和相关页面。 |
| 唱片材质与背景 | 选择盘面材质、背景、专辑外观与唱片底灯强度。 |
| 专辑专属外观 | 为某张专辑保存单独的材质和手动颜色。 |
| 自定义封面 | 选择本机图片作为该专辑封面；联动时封面由官方 App 提供。 |
| 桌面小组件 | 查看并配置唱片机的小组件入口；桌面添加方式取决于系统启动器。 |

自动配色开启时，封面色调优先参与显示；之前保存的手动颜色仍会保留。想固定背景颜色时，可关闭“随封面自动配色”。当前封面尚未取得时，会暂用已有颜色或默认色，不会凭空生成新封面。

**设置 → 聆听体验** 还可调整唱片与唱臂动画、自动收起工具、播放时常亮和落针音效。关闭动画可减少视觉动效，但这里没有经过验证的续航提升承诺。

## 音量与睡眠定时

本地及由唱片机管理的播放可在设置中调节音量，睡眠定时提供 **15、30、45、60、90 分钟**及关闭选项，到时暂停播放。

官方 App 联动使用手机系统音量；其睡眠定时由官方 App 设置。实际可用控制以当前页面为准。

## 后台、锁屏与切换显示尺寸

退到后台后，唱片机暂停不可见页面的动画与进度刷新，音频服务继续处理播放和锁屏控制。回到前台会重新同步当前歌曲；横向、较宽或紧凑显示切换会保留播放队列、进度与唱片姿态。

0.7.7 已在模拟器检查上述行为，并观察 45.065 秒本地测试音频后台状态。OPPO Find N6 / ColorOS 的真实折叠、后台限制及一小时以上播放仍待实机验证，不能用这次短时检查代替。

遇到锁屏后停止、返回页面重播或联动失效时，记录发生前后的操作和系统提示，按[反馈指南](../CONTRIBUTING.md)提交。
