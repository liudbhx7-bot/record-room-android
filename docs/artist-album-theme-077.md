# 0.7.7 专辑操作与自动配色

本轮只改原生专辑操作、自动调色及公共背景；不修改唱针几何、三枚实体播放键、音频权限或播放解析规则。保留手动选色、唱片材质和原有平面设置/搜索结构。

## 专辑操作

- 第一次点封套或“打开专辑”时，同时开始转正、抽片，并立即显示可用的“查看曲目”和“播放专辑”。动画不是操作门槛，展开也不会自动播放。
- 居中动画中可直接点另一个可见封套；旧唱片先收回，后续动画跟随最后一次选择。横滑、循环首尾、轻触反馈和同专辑位置恢复保持原合同。
- 页面隐藏或离开后，旧抽片及收回动画停止，保存最后选择的展开意图；取消的动画不能在后台继续改选中专辑或触发播放。
- 查看/播放在线专辑仍调用对应 provider 的完整专辑接口；不会把艺人搜索预览中的几首歌当作整张专辑。换片、收起、换章节后的迟到请求仍会被取消。
- 新增 `ArtistPage.create(Activity,List<Track>,String providerId,MusicProvider.Artist,Actions)`。艺人搜索即使没有歌曲，也可用真实来源与艺人 ID 进入，并请求完整资料；不创建虚构歌曲来代表艺人。

## 自动配色

黑白封面保持灰阶，不再因固定蓝色/棕色光照而偏色。彩色封面保留主色相，适度提高唱片输入色亮度并控制饱和度，让纹理叠加后的实际唱片仍可辨认。自动舞台根据唱片输入色留出亮度差；经典黑胶额外考虑其材质吸光，防止黑色纹理和背景接近。手动背景模式不受这些自动规则覆盖。

设置、来源、搜索继续使用平面色块。公共深色背景以中性深灰压低亮度，避免低饱和红色封面被固定蓝底抵消；原页面和滚动位置无需重建。玻璃表现仍用于现有悬浮工具，不扩展到内容卡片。

## 验证

最终定向 **85 项 / 12 类通过**。报告：`work/album-theme-refine-final/render-report.json`，日志：`work/album-theme-refine-final.log`。前三项红测分别复现了动画阻塞第二张真实点按、首点后缺少立即可用入口、黑色封面基础色分离不足。

覆盖真实触摸点选、立即查看与播放、无歌曲 seed 的真实艺人身份、完整专辑返回、隐藏中断、迟到请求取消、循环首尾、1200 张专辑虚拟化、恢复、关闭系统动画，以及设置/搜索/来源页面实时换色与滚动保持。

`cover-contrast-report.json` 的 12 组为黑、白、纯红、纯蓝封面 × 经典黑胶/默认泼墨/烟纹材质。原生截图测得：

| 指标 | 本组最低值 |
| --- | ---: |
| 唱片输入色与舞台基础色 | 3.936:1 |
| 实际纹理环带平均亮度与固定背景参照点 | 1.569:1 |
| 平面卡片主文字与卡片底色 | 11.377:1 |
| 平面卡片辅助文字与卡片底色 | 7.881:1 |

环带值是指定区域平均亮度的设计对照，不是对每一个沟纹像素的可访问性承诺。另有 8 种黑白/灰/高饱和颜色的基础色与文本检查，以及 9 款真实材质红蓝封面差异回归。主/辅文字检查对象为公共平面卡片颜色。

## 最后身份隔离修正

真实艺人入口接入完整缓存后，复核发现旧姓名匹配会把“同一平台、同名但不同艺人 ID”的歌曲和专辑混入。本轮最后增加 `ArtistIdentityIsolationTest` 的 4 项红测，旧实现全部失败，修复后与艺人操作、分页恢复、来源退出测试联合 **45/45 通过**。证据分别为 `work/artist-identity-red/`、`work/artist-identity-green/` 及同名日志。

明确 provider + artistId 的页面以同平台角色 ID 为准，姓名不能覆盖冲突；其他在线平台即使姓名、ID 字符串相同也不会合并。无平台身份的本地音乐和同平台缺失 ID 的旧资料仍保留姓名回退。唱片合辑中的专辑艺人关系与具体歌曲演唱者关系分别判断；真正同一专辑里的其他演唱者仍可作为完整专辑曲目保留。在线推荐标记只在过滤后确实还有该艺人的在线推荐歌曲时启用。

原退出隔离用例调整为没有目录身份的本地姓名浏览页，继续检查网易云退出只清网易云内容，保留 QQ/汽水缓存及可点击歌曲；它不再以“在明确网易云艺人身份页混入其他平台同名歌”作为成功条件。此最后修正未改视觉文件，因此前述原生视觉预览不变；最终交付以重新构建后的全量报告为准。

## 实际 APK 长专辑名布局修正

实际 QQ 艺人页出现的 `MULTIVERSE OF IPS 35TH ANNIVERSARY - 刘德华` 揭示了固定 116dp 信息区的裁切：原生红测在 412dp 普通字号下标题顶端越界 14dp，在 320dp、1.3 倍字号下越界 17dp。最后只将信息区改为按标题和操作内容测量高度，封套使用剩余空间；两个操作按钮采用 12–14sp 单行适配，触区仍至少 48dp。没有修改封面下载或抽片动画。

`ArtistLongAlbumLayoutTest` 新增 4 种布局，原版 2 项失败，修复后与艺人动作、恢复和渲染联合 **44/44 通过**。`work/artist-long-title-green/artist-long-title-{portrait,narrow-large-text,compact,wide}-{closed,open}.png` 共 8 张图使用上述真实长标题和已解码的演示封面，分别为 412×860、320×720 / 1.3 倍字号、726×320、900×420。竖屏允许两行并省略过长内容；紧凑横屏使用单行省略，所有可见标题和操作完整落在信息容器内。此证据验证原生布局，实际线上封面是否已加载、抽片是否完成由最终 APK helper 另行等待核验。
